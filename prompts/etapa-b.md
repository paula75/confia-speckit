# Etapa B – Mapeo

Continúa con la Etapa B del pipeline 7Cs → Spec Kit.

Usa todos los Canvas Object Models (COM) de la carpeta `com/` como entrada.

Ejecuta las siguientes skills:

- 7cs-business-context
- 7cs-architectural-context
- 7cs-system-context
- 7cs-structural
- 7cs-functional para cada Functional Canvas encontrado
- 7cs-deployment

Procesa todos los archivos COM correspondientes, incluyendo todas las instancias de Functional Canvas.

Guarda todos los resultados en la carpeta `mapping/`, siguiendo estrictamente el contrato definido por cada SKILL.md.

No ejecutes todavía `7cs-spec-compose` ni `7cs-spec-audit`.

Al finalizar, entrega un resumen indicando:

- qué archivos COM fueron procesados;
- qué archivos fueron generados en `mapping/`;
- si hubo advertencias o elementos marcados como `[NEEDS CLARIFICATION]`.
