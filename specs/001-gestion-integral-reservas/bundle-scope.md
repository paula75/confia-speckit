# Bundle Scope

## Objetivo

Este documento define el alcance que deberán utilizar las etapas posteriores de Spec Kit.

La Specification oficial continúa siendo `spec.md`.

No modifica, reemplaza ni duplica la Specification.

Su único propósito es restringir el alcance de planificación e implementación.

---

## Bundle seleccionado

Backend / Frontend Web (BW)

---

## Alcance funcional

Las siguientes etapas deberán considerar únicamente la sección:

> Requisitos funcionales — Bundle "Backend/Frontend Web" (BW)

incluyendo todos sus requisitos funcionales actuales y futuros.

---

## Dependencias permitidas

Podrán utilizarse únicamente como dependencias:

- Restricciones (R-*)
- NFR
- Integraciones de frontera (INT-*)
- Entidades compartidas
- Reglas de negocio utilizadas por el bundle

No deberán planificarse funcionalidades pertenecientes a:

- Bundle Agente Conversacional (AC)
- Bundle Backend Agendamiento (BA)

salvo cuando constituyan dependencias arquitectónicas explícitas.

---

## Restricción para las siguientes etapas

Las etapas:

- speckit-clarify
- speckit-checklist
- speckit-plan
- speckit-tasks
- speckit-analyze
- speckit-implement

deberán limitarse exclusivamente al bundle Backend / Frontend Web.

Este documento restringe el alcance de implementación.

No altera la Specification oficial, la trazabilidad ni los identificadores definidos en spec.md.
